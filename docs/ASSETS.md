# Original temporary assets

The pet uses a warm pear-shaped body, leaf-like ears, a sprout tuft and a sage scarf. Honey, sage and lilac body colours share the same geometry. The working name is Milo; the character/brand still needs final commercial clearance.

`app-icon.svg` is editable vector artwork. PNG icons are generated from matching shape primitives by `tool/make_assets.py`, including Android density variants. `wordmark.svg` uses a system sans-serif fallback. The in-app type system also uses the device font; no third-party font license or font download is required.

The Flame renderer is the source of truth for interactive pet poses. It supports idle breathing/blinking, happy, sleep, food, bubbles and simple accessories. It is temporary animation work, not a completed character animation library.

`room.wav` and `reward.wav` are original synthesized tones generated by the same script. Room music starts off. Recorded narration is intentionally absent; story UI currently says “Read together.”

No AI-generated screenshot or image is presented as an implemented UI capture. A real application screenshot must come from the first successful Flutter build.
